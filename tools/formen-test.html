Grundformen: Canvas gegen PixiJS

Der gesamte Zeichencode des Spiels läuft über einen Adapter, der wie ein Canvas-Kontext aussieht, seine Befehle aber als PixiJS-Geometrie ablegt (js/gfx-pixi.js). Diese Seite zeichnet jede verwendete Grundform einmal auf beiden Wegen und vergleicht die Bilder. Sie braucht keinen Server — einfach öffnen. Wer neue Zeichenbefehle benutzt, sollte hier einen Fall ergänzen.
